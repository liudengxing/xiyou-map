- `assets/js/app.js`：
  - `partyOf(n)` 多取一次 `awayAt(n)`，返回项带 `away` 标记；
  - 绘制处 `attr("class", "fig fig-" + c.id + (c.away ? " fig-away" : ""))`。
- `assets/css/style.css`：`.pin .party .fig-away { opacity: .38 }` + 描边虚线 `stroke-dasharray: 1.1 .9`。

## 为什么这么写

- 「被摄走」和「分头去办事」在数据上是同一件事：这个人这一回不在队伍边上。共用 `away` 一张表，只是 `why` 的字面不同，避免两个近似字段。
- 纸人不删、只画淡：删掉会让人以为「这站本来就没他」。画淡等于说「他在，但此刻不在这儿」。
- 被摄者同时从「同行」剔除、又在下一条「分期」里点名——两条是同一事实的两个视角，读起来不矛盾：上面说队伍里现在有谁，下面说谁为什么不在。
