# 第 001 轮 · 建立迭代归档基线

- **时间**：2026-11-26 18:20（Asia/Shanghai）
- **改动单元**：U-001-01
- **类型**：P0 骨架（过程性基础设施，不改页面行为）

## 为什么做这一轮

前期的实现（投影、路线、图钉、时间轴、详情卡、抽屉、深链、窄屏适配、标签避让重写）都已落盘并在浏览器里逐项验收过，但**状态只存在于会话上下文里**：仓库中没有 `docs/`，没有轮次记录，没有 U-ID，也没有待办池。后果是：

1. 每轮开工都要重新勘查仓库（README/行数/函数清单），重复劳动；
2. 已经测出的问题（标签重叠 4 对 / 压钉 9 处）没有落到文件，容易被遗忘；
3. 协议要求的「回退只前向」无从执行——没有历史可指。

所以第 1 轮先补齐基线，再谈后续内容与美化。

## 做了什么

新建四个文件：

| 文件 | 作用 |
