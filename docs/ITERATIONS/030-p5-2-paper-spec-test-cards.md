# 第 30 轮 · P5-2 paper spec 与测试卡

## 本轮目标

把实现文档第 5 节的 15 行 paper spec 定稿到 `scenes/huoyan/README.md`（改任何视觉决定前先改它，避免代码与设计两处真相），

3. `buildMs < 5000`；
4. `clips()` 为空（无纸片互穿）；
5. 资源 host 只有 `127.0.0.1:8123`（无 CDN）；截图落 `Z:/build-tmp/r30-p5-2-*.png`。

## 为什么这么改

- **spec 先落盘**：三条线（地面/人物/光）以后都要照着同一份色板与 BANNED 清单做，写进 README 后每轮能核对「有没有跑偏」，而不是靠会话记忆。
- **测试卡只在 `?test` 下印**：正式构图（P5-3 起）里不能留调试方块；用 harness 自带的 `flags.TEST`（`?test` 会同时把镜头拉近，正是判纸边的机位）而不是另造一个开关。
- **三张卡的分工**：单色看哑光与纸纹；双色看「同厚度的两块纸接缝是否露白边」；挖孔看 `holes` 的切口有没有厚度感——这三件是后面火墙/洞府/人物的共同前提。
- **没有改 harness**（硬约束），`thickness` 用 harness 固定的 `0.08`。
