## 参考图读到了什么、没读到什么

图像通道在本机只回元数据（尺寸 / 字节 / sha256），像素不进上下文，所以只能做量化：

| 量法 | 结果 | 能用的部分 |
| --- | --- | --- |
| 四角背景 + 差集遮罩 | 背景 `(217,151,83)`，遮罩占比 **96.7%** | 满幅手绘、没有零件白底 → **连通域分件走不通** |
| 量化调色板（面积排序） | `#ae3712` 13.6%、`#f4b96d` 13.3%、`#56260c` 11.9%、`#d18634` 8.9%、`#e8ab66` 8.7%、`#f8c27e`/`#fbd49b`/`#f9cf95` 各 ~7.5% | **配色可用** |
| 亮度分布 | `lum>0.78` 20.0%、`lum<0.25` 11.6% | 比纸艺设定图（亮部 44.2%）暗得多 → 深褐与朱红占比高 |

**没读到**：零件的边界、铰链的位置、卡片的层数。这些是设计判断，不是从像素反推出来的。

## 做了什么

`scenes/huoyan/wukong.js` 从 11 张卡改写成 **18 张卡的铰链纸偶**：

| 部位 | 卡 | z |
| --- | --- | --- |
| 躯干 | `wukong-torso`（y 1.12–2.46，半宽 0.38→0.42） | 0 |
| 躯干侧 | `wukong-torso-side`（y 1.18–2.40 内缩） | −0.10 |
| 头 | `wukong-head`（2.46–3.34）、`wukong-head-side` | 0.10 / 0.02 |
| 金箍 | `wukong-crown`（3.14–3.28） | 0.20 |
| 披膊 ×2 | `wukong-pauldron-l/r`（y 2.10–2.46，内缘 0.40） | 0.13 |
| 腰带 / 虎皮裙 | `wukong-belt`（1.30–1.44）、`wukong-skirt`（1.02–1.42） | 0.24 / 0.14 |
| 上臂 ×2 | `wukong-arm-l/r`（长 0.60） | −0.20 |
| 前臂 ×2 | `wukong-forearm-l/r`（长 0.58） | −0.30 |
| 大腿 ×2 | `wukong-thigh-l/r`（长 0.54） | −0.13 |
| 小腿 ×2 | `wukong-shin-l/r`（长 0.56，脚底 0） | −0.23 |
| 金箍棒 | `wukong-staff`（斜背，rotation.z 0.34） | −0.52 |

两级铰链：`wukong-shoulder-l/r` → `wukong-elbow-l/r`、`wukong-hip-l/r` → `wukong-knee-l/r`，共 8 个 Group。肘组 `(0, −UPPER, −(T+0.02))`、膝组 `(0, −THIGH, −(T+0.02))`，让前臂 / 小腿各退后一层，弯折时不与前段互穿。

配色换成参考图那族（`#ae3712` / `#56260c` / `#d18634` / `#f4b96d` / `#fbd49b` / 金 `#b8934a`），**没有一个蓝绿**。

## 验收（1256×774，本机静态服务）

| 指标 | 结果 | 判据 |
| --- | --- | --- |
| `window.__papercraft.ready` | `true` | 必为 true |
| `cards()` | **158**（v1 是 151） | 取景框内立卡数，+7 符合 18−11 |
| `clips()` | **`[]`** | 不许有互穿 |
| `buildMs` | 443–480 ms | < 5000 ms |
| 18 张 `wukong-*` mesh | 全部在场 | 名字齐全 |
| 脚底世界 y | **0.000**（`wukong-shin-l`） | 不悬空、不入地 |
| 髋摆动 | 左 0.358 / 右 −0.438（反相） | 反相且量级相当 |
| 膝屈 | 0.213 / 0.535（摆动相更大） | 只在往回收时屈 |
| 肩摆动 | 0.295（对应侧臂朝后） | 与同侧腿反相 |
| 肘 | 静止 −0.10，摆动到 −0.112 | 常留一点屈 |

第一次量到脚底 **0.020**（悬空）：髋枢轴 1.10 时，`1.10 − 0.54 − 0.56 = 0`，但卡的包围盒把纸厚算进来多了 0.02；把髋降到 **1.08** 后为 0.000。

## 为什么没有「看起来像不像」的结论

`bcdp_screenshot` 出的 PNG 我能存盘，但读不回来像素（`read_image` 只回元数据）。因此：

- 近景（dist 7.5 / 8 / 12 / 15 / 26，pitch 6 / 10 / 24 / 46）各拍了一张，逐张用 Pillow 量「与纸底差异 > 85 的像素包围盒」，结果都铺满全幅、主色是暗红 `(60–68, 0, 0)`。**这说明画面被某些前景纸件（火墙或地面阴影）填满，不能据此判断人物**，也就没有继续调参。
- 已存盘四张：`.tmp/r45-wukong-v3-scene.png`（默认构图）、`.tmp/r45-wukong-v3-test2.png`（`?test` 机位）、`.tmp/r45-wukong-v3-portrait3.png`、`.tmp/r45-wukong-v3-portrait4.png`。**像不像参考图，需要人看**。
