# 第 31 轮 · P5-3 地面焦痕 + 八百里火墙 + 芭蕉洞

## 本轮目标

把「空白纸地面 + 一枚立牌」推进成**能读出场景**的一幅静态全景：地面加焦痕（火墙脚下被烧过的地皮），
远景立起三层纸焰构成的八百里火墙，右侧偏前立芭蕉洞（洞口用 `holes` 挖穿、背后一张暗纸、两侧纸灯、两片石绿芭蕉叶）。
验收口径：`cards()` 100–250、`clips()` 空、`buildMs < 5 s`、全景截图落 `Z:/build-tmp/`。

## 可测指标（开工时列的 5 条）

1. `?` 普通入口 `__papercraft.ready === true`，`#fallback` 保持隐藏；
2. `__papercraft.cards()` 落在 **100–250**；
3. `buildMs < 5000`；
4. `clips()` 为空（纸片不互穿）；
5. 资源 host 仅 `127.0.0.1:8123`；截图 `Z:/build-tmp/r31-p5-3-wall.png`、`r31-p5-3-wall-2.png`。

## 为什么这么改

- **焦痕用径向渐变而不是实心块**：纸面上要像「洇开的墨」，实心块会读成贴图；半径 2.4–8.9 units、alpha ≤ .20，叠在地面纹理之上不改地面本身。
- **火墙用同一段轮廓反复钉**：八百里火墙靠「数量 + 抖动」出体积，不靠单张精细插画；`res` 压到 0.5–0.6 是 buildMs 的关键（三层 120 片，全分辨率印刷会顶到 5 s）。
- **洞口挖穿 + 背后一张暗纸**：`holes` 挖的是「纸被切掉」，后面必须有东西，否则透出的是场景背景色而不是「洞里的暗」——这是 P5-2 测试卡 ③ 的直接应用。
- **芭蕉洞放在偏右且比火墙近**（x 22 / z −18.6）：与 spec LAYOUT「火墙横贯远景，芭蕉洞偏右」一致，同时避免被火墙纸片吃掉。

**盲评 A/B 的诚实说明**：本轮 `read_image` 仍只返回图片元数据，像素没有进我的上下文，所以「火墙层次 / 洞门读法 / 焦痕是否像洇墨」这三件**没有肉眼结论**。

下一轮若视觉通道可用，第一件事就是判这一条；需要时把近层数量降到 26–30、远层降到 30 让焰尖之间露缝。

## 回滚方法

1. 删 `scenes/huoyan/scene.js` 里 `// ---- P5-3 八百里火墙` 到芭蕉叶循环结束（`}` 收在 `if (H.flags.TEST)` 之前）的整段；
2. 删 `printGround` 末尾的焦痕循环（`// 焦痕：火墙脚下…` 起 13 行）；
3. 调色板里 `shadow/gold/jade` 三行可留（P5-4/P5-5 还会用），也可一并删；
4. 恢复验证：`cards()` 回到 1（只剩立牌）、`ready` 仍 true。

## 遗留

1. **火墙可能糊成幕布**（见上，需肉眼判）；`res` 0.5 的远景焰在近看会略糊，正式构图再看要不要提到 0.65。
2. **地面焦痕的分布是伪随机**（`rnd()` 来自 harness 固定 seed），本轮没有按「越靠近火墙越密」做概率密度，只是把 z 范围收窄；如需「近墙密、远墙疏」，下一轮改成 `z = -44 + rnd()*rnd()*26`。
3. **芭蕉洞还没有 boxFold 的厚度感**：现在是「立面 + 背后暗纸 + 压边」三层平卡，spec 写的是 boxFold；P5-5 罗刹女站在洞口时会显得平，届时再换。
4. 洞门 `holes` 的切口没做内缘描边（`edge` 用默认 0.08），近看可能露白；判读未完成，留待视觉通道。
