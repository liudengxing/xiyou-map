## 改了什么（`scenes/huoyan/scene.js`，`U-036-01`）

`H.printGround` 回调内两处：

1. **压曝光**：`washes([C.deep, C.ochre])` → `washes([C.deep, C.ochre, C.ochreD])`，三档 alpha 由

2. **印花层**（四段，接在焦痕之后）：

## 中间试过的一版（记下来，免得下轮重走）

第一版是「1500 颗 0.35–1.2 px 的细砂 + 520 条 0.05 ppu 的细划 + 900 粒颗粒」，α 0.03–0.18。
结果 `printDetail` **一点没动**（0.002），`flatPct` 只降 0.2。原因是 `measure.py` 会把图缩到
1600 px 工作宽（我们的截图是 1256×774，等于**放大**），1 px 的细点被重采样糊成 0.03 的弱渐变，
过不了「梯度 > 0.10」这条线。第二版把砾石最小径提到 1.0–2.9 px、α 提到 0.18–0.48、并改成
「簇」而不是均匀噪点之后，`printDetail` 才动到 0.003。

**教训**：这套门限是按 1600 px 宽、且是「密集体块」（树、屋、篱笆）的画面定的；在 1256 的截图上
调细纹，等于跟重采样打架——要么按 1600 宽出图，要么把母题做大到 2 px 以上。

## 为什么 `printDetail` 还是 0.003

读 `scripts/papercraft/measure.py:608-618` 的定义：

```
gb = g[y0:y1]                        # sharp band 的梯度
printDetail = mean(gb > 0.10)        # ← 有多少像素「附近有明显边缘」
```

它量的其实是**清晰带里的边缘密度**，不是「纸张印花的浓度」。火焰山这张纸是
「塔克拉玛干那样一块空戈壁 + 一道火墙 + 一个洞」，清晰带的下半部是大片空地面；
要靠印纹把 6% 的像素顶到梯度 0.10，得铺上几十万个边缘像素——那就不是印纹了，那是往地上
倒碎石。要过这条门限，正路是**在清晰带里立更多不同的纸片**（石头、枯草、旗杆、骨片），
让「成组的体块」而不是「均匀的纹」去占面积。这已经超出「印花」的范围，单列成 BACKLOG P5-9。
