# 第 25 轮 · 全站次要边框的对比度分级 + 八十一难格子数字达标

## 本轮目标

第 23 轮把「收起态难号徽标」的对比度算清并修好，遗留里写着「同页其它 `.28–.45` 次要边框未动」。本轮做的是把它**分级**：先给全站边框定一条可执行的规矩，再按规矩逐个量、只改「真的必须改」的那几条。

判据（先写死）：
- 每一条边框都要能被归到「A 级：它是该控件唯一可辨形态」或「B 级：控件靠文字/图形就能认出来，边框只是围合」；
- A 级 ≥ 3:1（WCAG 1.4.11），B 级不强制但记录实测值；
- 控件内的文字仍按 4.5:1（WCAG 1.4.3）——**分级不能变成「边框不用管、字也可以不管」**；
- 三份校验脚本仍全通过，页面在 1440 / 390 下版式不变。

## 改动

### 1. 先量一遍（结论写进记录）

| 控件 | 边框 | 合成后对比度 | 分级 | 依据 |
| --- | --- | --- | --- | --- |
| `.tbtn` 工具栏 | `--rule` = `rgba(90,70,45,.24)` 于 `rgba(248,240,221,.7)` | **1.47:1** | B | 按钮有文字标签（行程表 / 八十一难…），文字即识别 |
| `.d-nav button` 翻页 | `--rule` 于 `rgba(255,252,243,.6)` | **1.49:1** | B | 按钮内写着前后站名 |
| `.nan-cell` 格子 | `--rule-soft` = `rgba(90,70,45,.13)` | **1.23:1** | B | 格内有难号数字 |
| `.tl-play` 播放 | `rgba(176,58,46,.45)` 于 `rgba(255,251,240,.85)` | **2.05:1** | B | 圆内有 ▶ 字形，字形本身 4.9:1 |
| `.nan-cell.done` | `rgba(176,58,46,.30)` | **1.49:1** | B | 已行格有底色 + 数字 |

结论：**全站没有 A 级边框**——每个可点控件里都有文字或字形承担识别，围合线只是纸上的墨框。所以「把 `--rule` 提到 0.62 才够 3:1」这个改法**不做**：那会让整页多出一圈圈深褐框，把宣纸的淡墨感毁掉，而它并不承载任何信息。这条判断写进记录，避免下次又有人拿 1.47:1 当成缺陷。

### 2. 真正不达标的是格子里的数字

按「控件内文字要 4.5:1」重新量 `.nan-cell` 三态：

| 状态 | 字色 | 底色（叠抽屉渐变后） | 对比度 | 结论 |
| --- | --- | --- | --- | --- |
| 未行 | `--ink-faint` `#9a8a72` | `rgb(249,243,228)` | **3.03:1** | ❌ 10px 数字看不清 |
| 已行 | `--cinnabar-deep` `#8c2b22` | `rgb(233,208,187)` | 5.72:1 | ✅ |
| 当前 | `#fdf3df` | `--cinnabar` `#b03a2e` | 5.46:1 | ✅ |

改法只有一行（`assets/css/style.css` 的 `.nan-cell`）：`color: var(--ink-faint)` → `color: var(--ink-soft)`（`#6b5c48`，5.84:1），并加注释写明原来的 3.03:1 与现在的 5.84:1，说明「仍比正文 `--ink` 弱一档，读得出『未行』而不用猜」。

没把 81 格全调成正文墨色：是「能读清」而不是「一样黑」，未行与已行必须一眼能分。

### 3. `scripts/check-contrast.mjs` 扩成两段

原脚本只查徽标；本轮加第二段「81 难格子三态」：新增 `ruleBlock(selector)` / `colorOf()` / `bgOf()` / `drawerBg()` / `nanCellStates()`，从样式表**现读** `.nan-cell`、`.nan-cell.done`、`.nan-cell.cur` 三块的字色与底色，以及 `.drawer` 的竖向渐变两端（格子底半透明，两端各算一次取更差）；任一处 < 4.5 就 `exit 1`。脚本 124 → 183 行 / 5112 → 7361 B。

## 为什么这么改

- **为什么不把 `--rule` 提亮**：见上表——A 级为零，提到 3:1 需要 alpha 0.62，整页会出现一圈圈深褐细框，与「宣纸设色」的淡墨基调冲突，属于「为了指标改坏设计」。把判断写进文档，比偷偷改掉更值。
- **为什么只改字色不改格子底**：底色承担「已行/未行/当前」三态区分，动了会牵动整张 9×9 的视觉节奏；字色只影响可读性，是这一项的最小改动。
- **为什么把三态都写进脚本**：只锁「未行」的话，将来有人把已行格调成 `--cinnabar`（4.07:1）或把当前格底改成浅色，脚本不会响。三态一起锁才闭环。

## 回滚方法（前向）

用户说「撤销 U-025」时：把 `.nan-cell` 的 `color: var(--ink-soft)` 改回 `var(--ink-faint)`（同时删掉那三行注释），把 `scripts/check-contrast.mjs` 里第二段（`ruleBlock` / `colorOf` / `bgOf` / `drawerBg` / `nanCellStates` 及 `81 难格子三态` 检查块）删掉、`OK：` 那行改回「徽标文字…徽标边框…」，并把 `README.md` 里「格子三态」的说明删掉。判据：`grep -c 'ink-soft' assets/css/style.css` 里 `.nan-cell` 那处消失、`node scripts/check-contrast.mjs` 输出回到只有徽标四行、`wc -l scripts/check-contrast.mjs` ≈ 124。记为 `U-026-01（回退 U-025-01）`。

## 遗留问题

- 分级只覆盖「主要可点控件」；`.tag` 的 `rgba(176,58,46,.4)` 边框、`.nan-cell.done` 边框、`.trip-item` 的左竖线等仍未逐条记录实测值（都属 B 级，但表里没写数）。
- 未在真实读屏器 / `forced-colors: active` 下复核（前者一直标「待核」）。
- 格子数字 10px 偏小（窄屏更小），可读性除了对比度还受字号影响；要不要提到 11px 是独立的观感决定，留给后续观感轮。
