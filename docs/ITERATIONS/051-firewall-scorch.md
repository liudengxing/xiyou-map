# 051 火墙降密 + 焦痕按距火墙取概率（Q4）

## 为什么做这一件
近层火墙是 44 片纸焰塞在 `halfW = 26` 的横向范围里，片间距只有约 1.2 个单位——比一片焰纸自己的宽度还小（近层 `scale ≈ 1.9×(0.72–1.34)`），于是 44 片糊成一条实心赭红色带，**读不出单片纸的裁切边**，纸模型的「一片片立着」这个最重要的语言在近层消失了。同时焦痕是把 18 片晕斑均匀撒在 `z ∈ [-44, -18]` 里，和火墙的实际位置（`z = -22`）没有关系，看起来像随机污渍。

## 做了什么
1. **近层降密 44 → 26**（`flameRows` 第三行），片间距约 2.0，接近焰纸自身宽度，焰尖之间露出空隙。远层（36）与中层（40）不动：那两层本来就该连成火脊。
2. **焦痕改为拒绝采样**，让它「按到火墙的距离取概率」：
   - 火墙位置固化为 `const WALL_Z = -22;`
   - 候选点 60 个，`x ∈ [-50,50]`、`z ∈ [-44,-6]`（覆盖墙后到近景，不再只撒在墙后）；
   - 距离归一 `d = min(1, |z - WALL_Z| / 18)`，`rnd() < d²` 就丢掉 → 贴墙概率接近 1，18 个单位外基本不再落；
   - `near = 1 - d` 参与两件事：半径 `r = (2.0 + near*4.2 + rnd()*4.0) * ppu`（贴墙的晕更大），芯色 alpha `0.10 + near*0.10 + rnd()*0.08`（贴墙更黑）。
   - 结果：贴着墙根是一片焦黑，往近景逐渐只剩零星几片——这是分布本身，不是手摆的。
