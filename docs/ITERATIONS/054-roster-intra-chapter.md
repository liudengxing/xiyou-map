# 054 逐回在场名单：回内粒度（Q7）

## 为什么做这一件
上一版 `away` 只能记「某一回某人不在队里」，判据是「这一站覆盖的回目区间里有没有这条记录」——于是整站一刀切：`present` 里有他就整站在，`away` 里命中就整站不在。真假美猴王这一站（第 56–58 回）把问题暴露得最干净：

- 第 56 回悟空打死拦路草寇、师父写贬书 → 他不在队里（回目「神狂诛草寇　道昧放心猿」）；
- 第 57 回他在落伽山、假猴王占水帘洞 → 仍不在（「真行者落伽山诉苦　假猴王水帘洞誊文」）；
- 第 58 回如来辨明真假、真悟空回队 → 他在（「二心搅乱大乾坤　一体难修真寂灭」）。

一刀切只能二选一：算他整站在（第 56–57 回就错了），或整站不在（第 58 回错了）。同理沙僧在第 57 回独自去花果山讨行李，第 56、58 回都在队里。

## 做了什么

1. **数据层**（`assets/js/data.js`）：
   - `away` 每条支持两种写法：`chapter: 57`（单回）与 `chapters: [56, 57]`（连回）；
   - 新增第 56–57 回悟空被逐一条（`chapters: [56, 57]`）；
   - 新增第 43 回八戒一条（「黑河妖孽擒僧去」，鼍龙弄翻船把唐僧与八戒一起摄走）；
   - `away` 上方补两行数据说明（怎么写、为什么只录能对着回目说清的）。
2. **判据层**（`assets/js/app.js`）：
   - `awayChapters(a)` 统一取回号数组；
   - `awayAt(n)` 改成「任一回落在站内区间」；
   - 新增 `charStatus(n, cid)`：算出这人在**本站覆盖的每一回**里在不在，返回 `null`（全在）/ `{kind:"away"}`（全不在）/ `{kind:"part", back}`（部分不在 + 回归回号）。
3. **渲染层**：
   - `partyOf(n)` 给每个纸人带 `away / part / back`；
   - 纸人 class 分三档：正常 / `fig-away`（整站离队，透明度 .38 + 虚线）/ `fig-part`（部分回目离队，透明度 .62 + 点线 `stroke-dasharray: 2 1.4`），并挂 `title="悟空（第 58 回归队）"`；
   - 分期行：单回写「第 57 回」，连回写「第 56 – 57 回」；`part` 的条目补「（第 58 回归队）」，回号标色改成石青（`.d-away-part b`）。
4. **回归回号的算法**（改了两版）：
   - 第一版取「站内第一个在队回」→ 沙僧在第 57 回外出，被写成「第 56 回归队」，读起来像他第 56 回才回来，反了；
   - 定稿：取**最后一个离队回之后**的第一个在队回（沙僧 → 第 58 回；悟空 → 第 58 回）；若离队之后没再回来，才退回「站内第一个在队回」，不硬造回归回号。

## 第 76 回那条「待核」的结论：存疑，不写入
BACKLOG 里挂着的「第 76 回八戒、沙僧是否同被擒」，本轮**没有足够依据**。现有材料里只有回目「心神居舍魔归性　木母同降怪体真」——「木母」指八戒，能读出的只有「八戒在这一回里有戏」，读不出他是否被擒、沙僧在不在。正文我没有逐字核过，按本项目的禁令（不杜撰回目与情节），**不写进 `away`，标「存疑」挂在 BACKLOG**，等以后能逐字核第 76–77 回原文时再补。

## 遗留
1. 回内粒度只做到「按回」；同一回内部的先后（例如第 56 回前半在队、后半被逐）仍表达不了，需要的话得记 `half: "前"|"后"`。
2. 纸人 `fig-part` 的「点线」在 1256 下只有 1 px 级，视觉上是否分得清「淡」与「点」**无法肉眼判读**（截图只回元数据）；数值上 class 与 title 都在 DOM 里可验。
3. 第 76 回存疑未决（见上）。
4. `away` 仍是手写表，没有从原文自动抽取的能力——这是设计选择，不是缺口。
