# 第 10 轮 · 标签候选位加「必须完整在屏内」的守卫（P4-6）

- 时间：2026-11-26 20:05
- 改动单元：`U-010-01`
- 优先级：P4 打磨（BACKLOG P4-6「屏外标签占用候选位」）
- 时间盒：约 15 min

## 1. 本轮目标

第 2 轮重写 `declutter()` 后，放置循环只在**起点**做了一次粗筛：

```js
if (sx < -50 || sx > W + 50 || sy < -30 || sy > H + 30) return;
```

这是「站点中心点」的粗筛，而候选位自身可以带 `dx: ±11 / ±22`（`CAND` 第 7–12 项）。于是两种残留会出现：

1. **整块落到屏外**：站点中心刚好在边界内，但 `dx: -22` 把它推到 `left = -60`（第 7 轮追查 `pinBite=1` 时抓到的实例就是「黄风岭」标签 `[-60,151,-33,163]`）。这种标签肉眼看不见，却仍然 `labelBoxes.push(...)` 占着位置，可能把本来放得下的邻站标签挤掉 —— 纯亏。
2. **只剩半截**：`left` 略微为负或右边越界，屏幕上出现半个字，看起来像渲染坏了。

本轮判据：**所有可见标签的包围盒必须完整落在视口内（四边各留 4px），且既有指标不回退**（1440 下仍 48 个可见、`pairs 0` / `bite 0`）。

## 2. 改了什么

`assets/js/app.js` 的 `declutter()`，放盒循环里、`pinHit(box)` 之前插入守卫（`assets/js/app.js:531-537`）：

```js
// 屏外候选位直接作废：整块落到视口外时，既看不见、又白占一个位置，
// 还可能把本来放得下的邻站标签挤掉（旧版只在起点做 sx/sy 粗筛，
// 左右两侧的 dx 候选可以把标签推出画面，实测 390 宽出现过 left=-60）。
// 只露出一半的标签同样要拒：贴边的半截字看起来像渲染坏了。
var EDGE = 4;
if (box.x < EDGE || box.x + box.w > W - EDGE
  || box.y < EDGE || box.y + box.h > H - EDGE) continue;
if (pinHit(box)) continue;
```

文件：`1247 行 / 47223 B` → `1254 行 / 47786 B`（`node --check` → SYNTAX_OK）。

## 3. 为什么这么改

- **放在候选位循环内**而不是循环外：每个候选位都要单独判，`dy: -43` 这类靠上的位可能在窄屏被顶栏切掉，`dx: -22` 靠左的位可能出左边界，条件不同。
- **拒绝而不是「夹回边界」**：夹回会造出一个和其它候选位重复的位置，贪心的「先到先得」语义就被破坏，而且夹回来的位置通常正好压着邻站。
- **`EDGE = 4` 而不是 0**：0 时字形的抗锯齿边贴着视口边缘，截图上看像被裁了一道；4px 是肉眼刚好看不出裁切的最小值。
- **不删候选位**：`dx: ±22` 在中段（站点居中时）仍是有效且好用的位，只是不该在边界上生效。

## 5. 回滚方法

前向回退，记为 `U-011-01（回退 U-010-01）`：

1. 删掉 `assets/js/app.js` 里 `declutter()` 的 `var EDGE = 4;` 与紧随其后的 `if (box.x < EDGE || …) continue;`（共 3 行）以及上方三行注释。
2. 恢复验证：390×844 下 `#s=0` 的可见标签数回到 12 且出现 `minLeft < 0`（改前实测 -0.7）；1440 下不受影响（仍 48 / 0 / 0）。
3. 其余文件无需改动。

## 6. 遗留

- 守卫只保证「盒不越界」，不保证「字不全被顶栏/工具栏遮住」：390 宽下 `.toolbar`（y 10–43）、`.search`（y 56–87）、`.chars`（y 96–127）、`.timeline`（y 744–844）都会盖住地图，落在这些带里的标签视觉上仍然「看得见但被面板压住」。要彻底解决得把面板矩形也当障碍传入 `declutter()` —— 涉及改名与重新量测，另立 **P4-8「把浮层面板矩形纳入标签避让」**。
- 未做真实读屏器验证（NVDA / VoiceOver），与前几轮一致，标「待核」。
