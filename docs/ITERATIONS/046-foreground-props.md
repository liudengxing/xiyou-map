## 为什么做这一件

`measure.py` 从第 36 轮起就一直挂三项 WARN：`printDetail`、`localContrast`、`barePct`。
第 45 轮的截图（`.tmp/r45-wukong-v3-scene.png`）实测是：

| 指标 | 值 | 门限 |
| --- | --- | --- |
| printDetail | 0.008 | ≥ 0.06 |
| flatPct | 92.5 | ≤ 70 |
| barePct | 93.2 | ≤ 58 |
| localContrast | 0.026 | ≥ 0.072 |

这不是「火墙不够多」的问题：远景 120 片纸焰已经铺满上半幅。问题是**清晰带是空的**。
measure.py 按水平带估模糊度，本场景的 sharp band 落在画面下半（每带模糊 5.7 / 5.1 / 7.7 / 3.4 /
1.7 / 1.2 / 1.1 / 1.0 / 1.1 / 2.0 px），对应的是相机与主角之间那块近地（z ≈ 0…18）——
那里除了纸纹什么都没有。

## 做了什么

1. **新建 `scenes/huoyan/props.js`**（`export function buildProps(H, C)` → `{ cards, clusters }`）。
   四类直边多边形纸件：
   - 纸石簇：大石背板 + 左小石 + 右中石 + 最前一片薄石（4 片）
   - 枯草束：四根两折的草叶 + 一片碎土（5 片）
   - 断旗杆：杆 + 断头 + 挂残的旗角（3 片）
   - 骨片干柴堆：两根错向斜柴 + 一节断骨 + 一片薄土（4 片）
   共 16 组 + 10 粒碎纸砾 = 77 片。同簇内相邻卡 z 间隔 `GAP = 0.09 > T = 0.08`，逐片 z 唯一；
   每片都过 `printTexture()`（横纹 + 散点，线宽 2 px、α 0.22–0.3）与 `floorContact()`
   （暖赭接触阴影 + 底缘压暗）。装饰件不设 `solid`，主角能穿过去。
2. **`scene.js` 加近地印刷**（`printGround` 内 P5-9 段）：清晰带里的地面本身也得是一张印过的纸。
   - 露出的石面：240 块不规则多边形，填充 `rgba(150,112,70,0.20…0.36)` + 硬边 `rgba(42,36,28,0.28…0.50)`
   - 砾石簇：340 簇 × 5–8 颗，点径 ≥1.5 px
   - 干裂短划：320 条两折硬线，`lineWidth` 1.4–2.8 × `nearPx`
   - 全部最小 2 px、α ≥ 0.24 —— 门限的标定宽度是 1600 px，1 px 的东西缩完就糊没了。
3. 版本号：`scene.js` 的 `import … './props.js?v=2'`、`index.html` 的 `scene.js?v=51`。

## 一次失败的尝试（记录，不要再走）

v5 加了 90 块「深赭第三色阶斑」（`rgba(96,66,40,0.20–0.30)`，6 边形），想按 WARN 提示补暗部。
结果**全部指标反向**：printDetail 0.044 → **0.013**、flatPct 63.4 → **85.7**、barePct → 90.5。
原因：这些斑块内部是纯色、边缘对比又不到 `grad > 0.10` 的门限，于是它们既不算「印」，
又占了原本有印花的地皮 —— 对 measure.py 来说就是「更大片的平色块」。
已前向回退（删掉该段，版本 `scene.js?v=51`）。

## 书面结论：这条门限为什么不适用于「空场荒漠」

P5-9 的验收原文是「`printDetail ≥ 0.06` **或**给出书面结论」。这一轮给结论：

1. **门限的标定集不对口。** measure.py 的 storybook 范围是在一款已上线的立体书游戏五个生境
   静帧上标定的（秋田、荒漠、雪原、春日花园、雾松林），那些画面里每个景深都有实物体块。
   本场景的构图是「一条火墙 + 一张空场 + 一个主角」，前景天生应当空 —— 空场是对的，
   正如门限提示自己写的「quiet ground between clusters is right」。
2. **printDetail 要的是硬边母题，不是暗部。** 实测证明：加暗块 = 加平色（v5 反向）；
   只有加**有硬边的线/点**才涨（v2→v4：0.037→0.044）。要在清晰的近地上把 0.044 推到 0.06，
   量级上还需要再翻一倍半的边缘密度 —— 那会让近地读起来像砾石混凝土，不像纸。
3. **正确的补法不是继续往地上画，而是立更多纸件**（本轮的 77 片已经进到 `cards 217`）。
   但要真正进入清晰带，纸件得摆在 z ≈ 8–15、每片屏幕高度 ≥ 60 px；再往上加就会挡住主角与
   芭蕉洞的取景 —— 这是构图取舍，不是印刷问题。
4. 因此本轮**不追 0.06**，把 `barePct 72.9` 与 `localContrast 0.059` 记为已知偏差，
   写进 BACKLOG 遗留；真正的解法在 P5-10（近景特写机位，让 sharp band 落在主角与纸石之间）。
