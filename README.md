# 西游时序 · 取经路线交互舆图

![西游时序 · 取经路线交互舆图 横屏宣传图](<pic/西游时序：取经互动舆图 横屏宣传图.png>)

把《西游记》一百回读成一条时间线：拖动底部的回目刻度，地图上的朱砂路线就会随取经队伍推进；点任一站点，右侧展开这一站的回目、难数、妖怪与情节。

纯静态站点，无依赖、无构建、无后端。**需要一个本地静态服务器**（浏览器对 `file://` 的 `fetch` 限制会让底图的两个 topojson 加载不到，页面只剩空地图），最简单的是：

```bash
python -m http.server 8123
# 然后访问 http://127.0.0.1:8123/
```

（第 35 轮 P5-7 验收把「双击即开」这条改成上面的写法：实测 `file://` 下 `assets/js/app.js` 的两处 `fetch()` 会被浏览器拦掉。要恢复双击即开，得把 `assets/vendor/land-110m.json`、`countries-110m.json` 包成带 `window.__LAND` / `window.__COUNTRIES` 的 js 文件——那要动 `assets/`，留作后续条目。）

## 「西游记有地图吗」

没有。《西游记》原书不附舆图，明代世德堂本、清代各刻本都只有文字与插图。今天能见到的各种「取经路线图」，几乎都是后人按章回顺序把地名连成的示意图——包括这张。

本书地名大半出于虚构（火焰山、狮驼国、女儿国），少数实有（长安、凉州、两界山、灵山），作者把它们串成一条「西行十万八千里」的线，先后次序并不严格对应真实地理。所以本站的站点位置是**示意**：虚构地名按原书行程排布，并在卡片里标注「小说地名 · 示意位置」；有实地的（长安、武威、敦煌一带）才落到真实经纬。

真实的西行另有一人：玄奘。贞观三年（一说元年）他从长安出发，经河西走廊、高昌、天山北麓、中亚碎叶，翻帕米尔南下，经迦毕试、犍陀罗入北印度，最后到那烂陀寺。这条路线见《大唐西域记》与《大慈恩寺三藏法师传》。点工具栏的「玄奘实路」可以把这条 23 点的实路叠在西游路线上做对照——两条线在葱岭以西分道扬镳。

## 怎么用

| 操作 | 效果 |
| --- | --- |
| 拖动底部刻度、点刻度 | 跳站，路线与详情随之更新 |
| 点地图上的站点图钉 | 选中并放大到该站 |
| `←` `→` | 上一站 / 下一站 |
| `空格` | 自动巡礼（播放 / 暂停） |
| `↑` `↓` | 同上，兼容翻页习惯（翻页键） |
| `/` | 聚焦搜索 |
| 搜「27」「第二十七回」 | 按回目号直达该回对应站点，无独立站点时给出最近一站 |
| `Esc` | 关闭抽屉、模态、搜索结果 |
| 滚轮 / 双指 | 缩放地图（最大 7 倍），拖拽平移 |
| 「行程表」 | 前传 5 站 + 西行 43 站的完整清单 |
| 「八十一难」 | 9×9 难格，已渡朱砂、当前金框，带进度条 |
| 「玄奘实路」 | 叠加真实路线与注记 |
| 「前传」 | 花果山 · 方寸山 · 龙宫 · 幽冥 · 天庭 的虚线轨迹 |
| 「随行」一行点唐僧/悟空/白龙马/八戒/沙僧 | 收拢到该人的行迹：队伍外的站淡出，自入队站起画一条石绿实线到灵山（悟空另带前传五站虚线），再点一次取消 |
| 「复位」 | 回到全图视角 |
| 「纪年」 | 时间轴上方标两处可考年月（贞观十三年·长安出关 / 历十四年·五千零四十八日·抵灵山），并在右侧平行列出史实玄奘的一程；小说写「贞观二十七年」而太宗崩于二十三年，两轨不可互算，所以中间年份一律不画刻度。默认开，深链 `&era=0` 可关 |
| 「今图」/「古图」 | 换底图的信息层：今图用现代城市点与境线、陆地换色，并收起古图的山形与海纹；路线本身仍是小说示意，古今切换只换「信息层」 |
| 当前站下的一排小纸人 | **只站在你行进到的那一站**，显示此刻队伍里有几个人：长安 1 → 两界山 2 → 鹰愁涧 3 → 高老庄 4 → 流沙河起 5；悟空被逐的那几回（第二十七至三十回、第五十六至五十七回）会少一个 |
| 点进「火焰山」站 | 自动摊开纸模场景（一张宣纸从上铺开再化开）；详情卡里也有「进入纸模场景」按钮。场景内走近 NPC 会自动弹纸片对话，NPC 与悟空头顶有纸签名牌，`Esc` 先收对话、再收场景 |
| 窄屏（≤900 px）点图钉 | 详情卡改成横铺的底部条并默认只露「回目 + 站名」，点卡内「展开」（或键盘 Enter）才展开全文，让地图留出更大一块 |
| 手机横屏（高 ≤480 px）| 时间轴压到 84 px、详情卡抬到距底 96 px、「随行」条挪到搜索框上方，让地图留出一条连续可看的带 |

深链可直接分享某一站：`#s=5` 是长安（索引 0 为花果山，5 起为西行），`&real=1` 同时打开玄奘实路，`&pro=0` 关掉前传图层，`&c=wukong` 直接进入悟空的行迹（可选 `tang` / `wukong` / `bailong` / `bajie` / `shaseng`），`&base=modern` 直接落在今图，`&scene=huoyan` 打开纸模场景，`&era=0` 收起纪年层。

## 数据从哪来

- **一次跑完**：`node scripts/check-all.mjs` 会把下面三条校验依次跑一遍，末尾给一张汇总表，任一失败就非零退出（改完数据/样式跑这一条即可）。

- **回目一百回**：取自中文维基文库《西游记》目录，繁转简后录入 `assets/js/data.js` 的 `chapters`。
- **八十一难名目**：第九十九回难簿原文，按次序录入 `nan`；其中第八十难「凌云渡脱胎」在难簿内，第八十一难「通天河遇鼋」是菩萨临时补入的，原文如此，未作改动。
- **站点情节**：据各回原文自述，不伪造引文。卡片里的引句只用两处核实过的原文——第七回「皇帝轮流做，明年到我家」、第十三回法门寺「心生，种种魔生；心灭，种种魔灭」。
- **底图**：Natural Earth 110m 简化地物（public domain），经 world-atlas 打包为 TopoJSON，随仓库带在 `assets/vendor/`。
- **绘图**：d3 v7（geoMercator + zoom）与 topojson-client，均为本地文件，无 CDN 依赖。
- **站点分类数字**：「关于」里「今地可考「8」/ 虚构境域与国度「15」/ 小说地名「24」」是按每个站点 `modern` 字段算出来的，改过地名或加站之后跑 `node scripts/check-stations.mjs` —— 它会同时校验 48 站、100 回目、1–81 难无缺无重，并把 `index.html` 里那三段文案的数字与实际分档比对，不一致就非零退出。
- **海面水纹**：32 簇波浪线，坐标必须落在开阔水域——改点后跑 `node scripts/check-seamarks.mjs` 校验（脚本用同一份 `land-110m.json` 与 `d3.geoContains` 逐点判陆地，有点落陆就非零退出）。
- **对比度**：① 收起态「第 47 – 49 难」那枚小徽标，文字与边框必须对底色达标（文字 ≥ 4.5:1、边框 ≥ 3:1）；② 八十一难抽屉里 81 个格子的数字分「未行 / 已行 / 当前」三态，都要 ≥ 4.5:1。改样式后跑 `node scripts/check-contrast.mjs` —— 它从 `style.css` 现读色值与 alpha，把纸底、卡顶/卡底渐变、吸顶卡头、抽屉渐变两端都算一遍取最差，不达标非零退出。

## 文件结构

```
index.html              单页骨架：地图、详情卡、时间轴、抽屉、模态
assets/css/style.css    宣纸设色：经纬网、海岸描边、朱砂路线、印章标题
assets/js/data.js       回目、八十一难、48 个站点、玄奘实路、地名注记
assets/js/app.js        投影、路线、图钉、时间轴、详情、搜索、深链
assets/vendor/          d3.min.js、topojson-client.min.js、land/countries-110m.json
scripts/fetch.sh        取底图用的原始下载脚本
scripts/check-seamarks.mjs  海纹坐标的水面校验（node，无第三方依赖）
scripts/check-stations.mjs  站点/回目/难号与「关于」分类数字的一致性校验（node，无第三方依赖）
scripts/check-contrast.mjs  徽标 + 81 难格子三态的 WCAG 对比度校验（node，无第三方依赖）
scripts/check-all.mjs        一次跑完上面三条校验（node，无第三方依赖）
.tmp/                   调试图（iframe 预览页），可删
```

站点尺度不写死像素：`app.js` 按视口算一个 `U` 系数写进 `--u`，图钉半径、标签字号、线宽、山形符号都跟着变；窗口缩放会重排标签避让。
